# CampusFix - Project Charter

## 1. Project Name
CampusFix - Campus Maintenance Reporting System

## 2. Project Overview
CampusFix is a web-based system designed to make it easier for students to report maintenance problems on campus.

Students can report problems such as broken air conditioners, lights, fans, toilets, Wi-Fi, and other campus facilities. University staff can view the reports, organize maintenance requests, and update the status of each problem.

## 3. Problem Statement
Students sometimes find maintenance problems on campus but do not know who to contact or how to report them. Because of this, some problems may take a long time to be reported and fixed.

## 4. Project Objective
The objective of CampusFix is to provide students with a simple way to report campus problems and help university staff manage and track maintenance requests.

## 5. Target Users

### Students
Students can:
- Report maintenance problems
- Select the building or room
- Select the type of problem
- Describe the problem
- Check the report status

### University Staff
University staff can:
- View submitted reports
- Organize maintenance requests
- Prioritize problems
- Update the report status
- Mark problems as fixed

## 6. Main Features
- Report a campus problem
- Select room or location
- Select issue type
- Add a problem description
- Track report status
- Staff dashboard
- Update maintenance status
- AI chatbot assistance

## 7. Project Scope
The first version of CampusFix focuses on reporting and tracking campus maintenance problems such as:
- Air conditioner problems
- Broken lights
- Broken fans
- Toilet problems
- Wi-Fi problems
- Other facility problems

## 8. Expected Result
CampusFix should make communication between students and university maintenance staff easier and help campus problems get reported and fixed faster.
